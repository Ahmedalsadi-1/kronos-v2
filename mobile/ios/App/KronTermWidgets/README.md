# KronTerm iPhone system surfaces (Labs)

The `KronTermWidgets` extension is embedded in the App target. It includes small and medium Home Screen widgets, circular and rectangular Lock Screen widgets, and a compact / expanded Dynamic Island Live Activity. The extension requires iOS 17. The app still supports its existing deployment target; this Live Activity extension requires iOS 17 or later and user permission.

`KronTermWorkspace.update` stores a bounded, credential-free summary in the App Group, refreshes widgets, and starts or updates a single foreground-created Live Activity. A terminal status ends the activity after a brief result display. `end` removes the Live Activity immediately and resets the shared widget snapshot. The TypeScript wrapper is `mobile/src/lib/native-workspace.ts`.

Both targets need the `group.dev.kronterm.iphone` App Group enabled in the selected signing team's provisioning profiles. The source entitlements already declare it. Widget and activity links use `kronterm://surface/<surface>?task=<taskID>`; route them through `parseWorkspaceDeepLink` and Capacitor App URL events. Only a validated, paired session should resolve the surface. These URLs carry identifiers, never credentials or commands.

Widgets display the last received snapshot, with its relative update time. Widget refresh timing belongs to iOS. Live Activity content becomes stale after five minutes without an update. Local result/attention notifications are available only after the user explicitly requests permission. They contain generic text and route to a validated surface, with no task text on the notification. Only a same-task transition from running to waiting, or from running/waiting to completed/failed, posts a notification; the initial snapshot and repeated states stay quiet. They reflect updates actually received by the app. This implementation has no APNs registration or server push integration; it cannot keep updating a suspended or terminated app from a remote runtime. It has no pause or approval buttons because opening a validated task in the app is the implemented action.

Run `npm --prefix mobile run ios:sync` before an Xcode build so Capacitor's generated resources exist. Select a signing team for both targets and build App on a supported simulator or iPhone. No Xcode iOS SDK was available on the implementation host, so native compilation and runtime verification remain required.
