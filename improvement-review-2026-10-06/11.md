# 11 - OS shell command center

Scope: sampled `frontend/app/workspace/kronarchy-shell.tsx`; root AGENTS.md and KronTerm OS skill/context read. Read-only source review; no runtime reproduction or builds.

## P1 - Make keyboard activation follow the focused result

**Observed:** `frontend/app/workspace/kronarchy-shell.tsx:511` intercepts every bubbled Enter and invokes `activeItemId`, while rows at :579 are native buttons (confirmed in `frontend/app/components/system-ui/system-ui.tsx:116`). Selection changes on mouse enter (:596) and arrow keys (:532), but not keyboard focus. Tab can therefore focus a different button without updating selection; Enter prevents its default click and activates the previously selected result. Arrow navigation also changes only styling, with no scroll or accessibility selection relationship.

**Acceptance:** Tab to the second result and Enter launches exactly that result once. Search-input Enter launches the active result. Arrow navigation keeps the active result visible and exposes its label to assistive technology; use one consistent native-button or combobox/listbox interaction model. Add focused interaction coverage for Tab, Enter, filtering, and arrows.

## P2 - Replace the hand-written modal boundary with a shared focus scope

**Observed:** :494 traps only Tab at first/last elements; :555 sets `aria-modal`, but `SystemPopover` (:67 in system-ui.tsx) is merely a section with dialog role. Neither establishes background inertness or handles programmatic focus escape. :425 queues initial focus without canceling its animation frame. **Hypothesis:** other live workspace surfaces can steal focus while Command Center remains open; confirm in Electron with terminal/native surfaces and fast toggle sequences.

**Acceptance:** while open, keyboard and programmatic focus remain inside; background controls cannot activate; Escape/backdrop dismissal restores a connected previous target; rapid open-close does not steal focus afterward. Preserve live block identities and use the shared System UI wrapper.

**Verified upstream pattern:** [Radix Dialog source](https://github.com/radix-ui/primitives/blob/main/packages/react/dialog/src/dialog.tsx) composes FocusScope, DismissableLayer, background hiding, and close-focus handling. This is a behavioral reference for the modal boundary, not a palette replacement. [License](https://github.com/radix-ui/primitives/blob/main/LICENSE) is MIT: retain notices if copying source. Prefer wrapping an existing installed primitive; adopting the package adds transitive focus/scroll dependencies and requires Electron/native-surface integration checks. Main-branch source is mutable: pin the reviewed release before adoption. Keep KronTerm materials, typed app lifecycle, and shell ownership local.
