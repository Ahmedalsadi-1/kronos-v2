# Apple System UI Reference

Use Apple guidance to define hierarchy and behavior, not to reproduce macOS branding.

## Adopt

- Integrate contextual controls into window chrome and keep titles concise.
- Group toolbar actions by navigation, frequent actions, and durable trailing actions.
- Move lower-priority toolbar items into overflow as width narrows without shrinking hit targets.
- Use a leading sidebar for peer destinations and shallow hierarchy; collapse it when content width becomes constrained.
- Let accent, light/dark appearance, contrast, transparency, and motion follow system and user settings.
- Use distinct semantic materials for content, window chrome, bars, sidebars, menus, and popovers.
- Keep content backgrounds opaque and legible. Material is a hierarchy tool, not decoration.

## Do not copy

- Apple branding, window artwork, SF Symbols, source code, proprietary assets, or exact application layouts.
- System controls that KronTerm cannot honestly operate.
- Decorative glass across every content surface.
