## Concrete KronTerm opportunities

1. Record a user demonstration into a reviewable reusable skill, including prerequisites and a dry-run verification. Inspired by actual installed Manus components; do not copy proprietary implementation.
2. Shared editable artifacts: user and agent mutate the same timeline, canvas objects, game parameters or document model, preserving manual edits.
3. Game tweak widget: generated typed controls for speed, gravity, damage and spawn rates, alongside live preview and asset inventory.
4. Video timeline widget: layered media, audio and captions, targeted revision, preview and export.
5. Canvas operations: selected objects/layers as scoped inputs, library rules and attributable agent activity.
6. Batch asset variants: one template plus a data table produces controlled locale/size/content variants.
7. Existing-app adapters: connect installed ComfyUI and existing browser tools through supported interfaces instead of requiring duplicates; live endpoint discovery remains future work.
8. Persistent jobs: explicit local/remote execution destinations, durable artifacts and resume. Extend existing cron, webhook and sandbox foundations.
9. Adaptive delegation: optional routing with measured quality, latency and cost; preserve chosen provider settings.
