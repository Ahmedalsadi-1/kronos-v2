# Computer host helpers

Vendored from thomasbek3/hermes-bot-kit commit
4bfdd1bf3c7ad20458e4793666550af760b76d97 under the adjacent MIT license.

Run `connect-mac.sh`, `connect-linux.sh`, or `connect-windows.ps1` on the machine
to share, then paste the printed address into KronTerm's Computer widget.
The `hiperf-*` scripts provide optional H.264 streaming. `orgo-term` and
`orgo-hands` provide Orgo terminal and desktop control from a shell.

These scripts are included for explicit setup; opening the widget does not run
them. See https://github.com/thomasbek3/hermes-bot-kit/tree/master/computer-viewer
for prerequisites, permissions and platform limitations.
