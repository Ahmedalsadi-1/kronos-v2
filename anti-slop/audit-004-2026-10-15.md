# Revised cursor feedback audit

This supersedes audit-003's visual assessment, which did not compare the native references adequately.

The user reported jitter, following the human pointer, and a visual mismatch. These fixes are explicitly requested by the user.

## Reference evidence

- Ego Lite's native agent space was opened and observed during repeated agent pointer actions. It uses a dark pointer, soft neutral shadow, and dark rounded action label.
- Open Computer Use source inspected: https://github.com/iFurySt/open-codex-computer-use/blob/main/packages/OpenComputerUseKit/Sources/OpenComputerUseKit/SoftwareCursorGlyphRenderer.swift and SoftwareCursorOverlay.swift. The procedural renderer uses neutral fog and subtle pointer compression with a 160 ms sinusoidal press.
- Revision preview: `output/cursor-feedback/preview-v2.png`.

## Changes and checks

- Removed invented blue target rings and expanding blue click waves.
- Replaced per-update animation restarts with one continuous critically damped loop that preserves velocity through target updates.
- Removed human mouse listeners from the injected cursor and preview. Only explicit agent commands drive it.
- Reduced motion preserves static feedback.
- Ownership, duplicate updates, retarget continuity, frame-rate independence, script serialization, and disposal have focused regression coverage.

No additional actionable visual findings in the inspected preview. The implementation follows the observed reference traits; it is not a pixel-exact copy. Packaged native overlay has not been visually exercised.
