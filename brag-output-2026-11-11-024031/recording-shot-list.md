# KronOS launch film: replacement recordings

These five takes replace the staged development UI in this iteration. Record each as one uninterrupted take with two seconds of stillness before and after the action. Use a clean demo workspace and synthetic content.

Capture at native Retina resolution, ideally 3840 x 2160 at 60 fps. Keep the cursor still during holds. Turn off notifications. Avoid moving the recording window or changing scale between takes. Keep system audio separate from narration; this cut uses music and sound design.

## 1. The notch agent — 12 seconds

Start with the compact notch visible above the workspace. Expand it, type a short real task, and pause before submitting. Submit a harmless workspace inspection request. Hold on a genuine response, then collapse the notch. Capture the actual expanded panel with its available surface controls; do not substitute a sidebar chat.

Suggested request: “Show me the browser, terminal, and files in this workspace.” Only keep a response if those surfaces are actually present.

## 2. Widgets working together — 15 seconds

Place a browser, terminal, and file or code widget in the same workspace. Move one widget, resize it, then switch from the spatial view to the overview and back. End with an intentional composition: browser dominant, supporting terminal and files clearly visible.

Use a small local project with a beautiful rendered page. Avoid blank terminals, repository homepages, tiny unreadable windows, and menus covering the main content.

## 3. Inside the sandbox — 18 seconds

Open a running sandbox computer. Show its browser, terminal, and files in sequence. Run a harmless command such as `pwd`, open a demo file, then return to the browser preview. If agent control works, capture the real handoff and its resulting action in a separate take.

The video needs the sandbox doing something visible, not just its configuration or an idle status card. Do not include credentials, private paths, or unrelated terminal history.

## 4. n8n — 15 seconds

Use a real connected demo workflow with at least three meaningful nodes. A good safe example is Manual Trigger → Edit Fields (synthetic launch copy) → another local transformation. Fit the graph, select a node, show its configuration, then execute only if all effects are local and safe. Hold on the true result.

Avoid an empty workflow picker or a two-node “Example step” graph as the hero shot. Do not use production automations, email sending, or external publishing for this capture.

## 5. ComfyUI — 18 seconds

Open an installed, working image workflow with its actual model and connected nodes. Fit the graph, zoom toward the prompt and sampler, then show an image that the workflow really produced. Capture the same graph inside the KronOS canvas with another widget beside it.

If no image model is installed, record the node canvas and controls only. Do not show a generated image as though this workflow produced it.

## Optional closing take — 8 seconds

Return to the composed workspace, with the notch, widgets, and workflow surfaces in context. Move the cursor to an empty corner and hold. This is the final product reveal and the best candidate for the poster.

## Delivery

Keep the original recordings without editing or recompressing them. Name files `01-notch`, `02-widgets`, `03-sandbox`, `04-n8n`, `05-comfyui`, and `06-workspace`. Include a short note for any feature that is a development preview or requires setup.
