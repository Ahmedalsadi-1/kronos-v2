# KronOS orbital star

The static SVG is a reconstruction of the final pose in the supplied orbital-star clip. PNG exports derive from this vector. The MP4, WebM, and GIF assets preserve the supplied animation; light variants invert its colors. The source animation is approximately two seconds at 434 × 368.

Use the SVG for regular branding and the favicon files for browser tabs. The canvas loading view uses the theme-appropriate MP4 with a static fallback when reduced motion is enabled.
