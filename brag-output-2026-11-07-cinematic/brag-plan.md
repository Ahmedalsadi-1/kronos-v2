# KronTerm: the office comes alive

80 seconds, 1920x1080, 30 fps, stereo, instrumental, no narration.
The supplied 80-second brief overrides /brag's 15-25-second default.

## Planning rubric

1. KronTerm is a persistent workspace for human and agent work across browsers, terminals, files and computers.
2. The strongest demonstrated moment is a request that identifies a browser by its contents, followed by navigation in that same browser.
3. The hook is Coucou waking inside a dim laptop display and triggering the room's light response.
4. Use the continuous Maps-to-Python browser recording, real element selection, OS navigation and recorded computer/device work.
5. 80 seconds preserves the requested room setup and the browser interaction.
6. Cinematic: restrained dark surfaces, 34-degree camera field of view, shallow perspective, stationary reading holds.
7. Sparse ambient instrumental music and quiet action sounds; no narration.
8. Share caption: KronTerm. One persistent workspace for your tools and agents. macOS private beta.
9. Request -> identified browser -> navigation -> loaded Python tutorial. Selection -> property controls -> copied-element feedback. An applied property change and prompt result were not verified.
