# KronTerm Marketing Strategy

## Product Overview
KronTerm (based on Wave Terminal) is an open-source, AI-integrated, cross-platform terminal for seamless workflows. It combines a powerful terminal with AI assistance, durable SSH sessions, and a flexible block-based workspace.

## Key Differentiators

### 1. AI-Native Terminal Experience
- Context-aware assistant reads terminal output and scrollback
- File operations with automatic backups and user approval
- BYOK support (OpenAI, Claude, Gemini, Azure, Ollama, LM Studio)
- No accounts required - bring your own API keys

### 2. Durable Remote Workflows
- SSH sessions survive network interruptions and restarts
- Automatic reconnection without losing context
- One-click remote connections with full terminal and file system access
- Connected file management between local and remote hosts

### 3. Flexible Block-Based Workspace
- Drag & drop interface for terminal blocks, editors, web browsers, and AI assistants
- Command Blocks for isolating and monitoring individual commands
- Rich file preview (markdown, images, video, PDFs, CSVs)
- Quick full-screen toggle for any block

### 4. Developer-First Design
- Built-in editor with syntax highlighting for remote files
- wsh command system for CLI workspace management
- Secure secret storage using native system backends
- Cross-platform (macOS, Linux, Windows)

## Marketing Strategy

### Target Audience
**Primary:** DevOps engineers, SREs, and backend developers who:
- Work with remote servers via SSH daily
- Need AI assistance for debugging and code analysis
- Value workflow efficiency and context preservation
- Prefer open-source tools with BYOK flexibility

**Secondary:** Full-stack developers, platform engineers, and technical leads who:
- Manage multiple environments (dev/staging/prod)
- Need integrated file editing and preview
- Want AI assistance without vendor lock-in

### Core Promise
**"Your terminal, supercharged: AI that understands your workflow, SSH that never drops, and a workspace that adapts to how you work."**

### Proof Points

### Success Metrics

#### Primary Metric: **Weekly Active Users (WAU)**
- **Target:** 5,000 WAU within 3 months
- **Measurement:** Telemetry (opt-in) + GitHub stars as proxy

#### Secondary Metrics:
1. **GitHub Stars** - 2,000 stars within 3 months
2. **Community Growth** - 1,000 Discord members within 3 months
3. **Content Engagement** - 10,000 blog views/month
4. **Contributor Growth** - 10 new contributors/month

### Constraints
1. **No paid advertising** - Organic growth only
2. **No fake testimonials** - Authentic community voice only
3. **No vendor lock-in claims** - BYOK model means users control their data
4. **No feature creep** - Focus on core terminal + AI + SSH value
