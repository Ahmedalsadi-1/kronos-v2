Observed: `/Users/albsheralsadi/kronterm/frontend/app/view/preview/preview-directory.tsx:434` obtains all sorted rows, then lines 476-487 render every non-parent entry as a `TableRow`. Each row renders its visible cells. The number of mounted row components therefore grows with directory size, independently of viewport height. No runtime profile establishes the latency, memory impact, or frequency of affected directories. Treat this as a bounded performance improvement candidate, not a demonstrated production incident.
