# Composer widget and takeover audit

Mode: after building, as selected by the user. Scope: the Manus-reference chat composer, widget strip and takeover flow.
Direction: the supplied dark Manus screenshot and recording, adapted to KronTerm's bot identity and real widgets.

## Findings

1. **HIGH — R-35, original-source reconstruction remains partial.** Manus's compiled frontend was inspected directly,
   but the original Grok Bot source was not supplied or found. REA did not finish its analysis. See
   `../MANUS-UI-REFERENCE.md` for exact artifact locations, hashes, observations and limitations.
2. **HIGH — R-35 / C-4, native fidelity remains unverified.** Physical iPhone testing and native compilation are missing.
   Asset sync alone does not validate WKWebView snapshots, keyboard behavior or device performance.
3. **MEDIUM — C-4, browser thumbnail fidelity.** The local browser miniature renders a read-only viewport of the same
   URL, rather than capturing exact scroll, login and dynamic state from the interactive view. Some sites prohibit frames.
4. **MEDIUM — C-2, engine scope.** The temporary graphical desktop and saved console VM are still different guests.
   The local model's VM tools do not control the graphical guest or interactive browser DOM.
5. **LOW — C-4, handoff validation.** Local takeover interruption is unit-tested and the browser exit/note flow was
   exercised. An actual model continuation and a connected Mac continuation need configured providers and device testing.

## Passed checks

- Widgets occupy a shared strip above the composer; the active widget is larger and multiple others remain visible.
- Preview click handlers receive the exact surface and browser-page identity.
- Local widget panels remain mounted while hidden, preserving tabs and temporary desktop state during view switching.
- Direct browser input is disabled in watch mode and restored during takeover.
- Exit takeover opens the note dialog. Missing model configuration preserves the note and opens settings.
- Takeover waits for a cancelled local model operation to settle before enabling input.
- Current build and iOS asset sync pass; 52 mobile tests pass.

No fixes were applied as a result of this post-build audit. This remains a Labs prototype.
