## Reuse

- Hermes smart delegation wraps the bundled official ModelMap provider instead of owning a second model router. It already validates scope, exact required tools, batch size 1–4, and homogeneous delivery. Its worker context and evidence handoff are useful seams for a typed swarm adapter (agents/hermes/plugins/kronterm-tools/delegation.py:59, :124, :144, :154, :167, :216).
- Electron DelegationPolicy pins caller identity and computer control generation, grants one worker per computer, combines worker and lease abort signals, and keeps capacity until tracked operations settle. Native bridge also aborts on client disconnect and labels uncertain mutating failures. Preserve these fences when adding queues or routing (emain/delegation-policy.ts:63, :78, :121, :143, :164; emain/kronterm-tool-server.ts:768). Retain independent per-target serialization where UI mutation is shared.
- ACP specialist execution provides scoped sessions, startup interruption, deadline and stop cleanup, explicit approval routing, partial-stop detection, and ordered privacy-safe event metadata. The guard is instance-local (native server reuses one bridge at emain/kronterm-tool-server.ts:538; workflow creates per-run bridges at emain/workflow-runtime.ts:104). Keep that as a backend policy while introducing an explicit per-provider/per-run semaphore. Standalone CLI ACP entry points explicitly require the native runtime (mcp-kron-term/src/wsh-bridge.ts:1084).
- The tool wrapper already provides deadlines, request IDs, typed uncertainty and settlement tracking. It reports latency/transport/attempts in bounded diagnostics (mcp-kron-term/src/tool-execution.ts:110, :143, :193, :220). Preserve uncertainty and require observation before retrying mutations.
- The WorkflowStore already models crash reconciliation. In-progress workflow steps become blocked/uncertain on load and require reconciliation (emain/workflow-store.ts:175). Reuse this semantics for durable swarm jobs and stable task IDs. Store authoritative transitions and evidence references, with ephemeral token/cursor events on a separate throttled stream.

## Prioritized findings

1. **High confidence, worker deadline loses ownership across child startup gaps.** ActiveWorkers.watch snapshots only currently registered children; started() records a late child with no expiry check; the LLM hook calls interrupt but still invokes next_call. stopped() finishes the shared timer whenever the current map is empty, even while other admitted tasks have yet to start. This can happen in serial/cap-limited dispatch, or when one short worker finishes before its peers register. The Electron lease independently fences tools at expiry, but pure model work can outlive the intended budget. Use an explicit outstanding admitted count plus a closed-dispatch flag, make cancellation terminal for late starts, and skip provider calls after expiry. Regression: fake budget and barrier-driven hooks for start A, stop A, delay start B beyond deadline; assert timer stays armed, B never dispatches a model request, and each child receives at most one interrupt. Also inject one interrupt error and verify siblings are still interrupted. Evidence agents/hermes/plugins/kronterm-tools/delegation.py:42, :233, :240, :273.
2. **High confidence, post-result delegation guard is not an admission guard.** The lock protects lookup of completed_turns, then releases before preflight/dispatch; the marker is set only after a qualifying result. Parallel calls in one turn can each launch a batch and the early completion marker then hides the delegation tool while peers remain active. Introduce an atomic turn/run admission reservation, retaining idempotent replay by stable batch ID, with separate admission and handoff state. Regression: synchronize two same-turn calls at prepare for widgets/inherit and assert only one launches, while a refused preflight releases its reservation. Evidence agents/hermes/plugins/kronterm-tools/delegation.py:116, :167, :194, :216.
3. **High confidence, lease concurrency cap is checked before asynchronous readiness.** prepare() tests map size before await inspect. Multiple requests for distinct computers, or a delayed sandbox preflight followed by non-computer admissions, can overrun the 256-lease limit. Also the limit counts leases, each reserving up to four workers. Recheck at insertion, and implement bounded worker-slot admission by caller/provider/target before spending resources on provider startup. Regression: seed 255 leases, hold a sandbox readiness promise, admit a widgets lease, resolve readiness, assert the sandbox request receives capacity rejection. Add quota/drain tests tracking slots through cancellation and pending tool settlement. Evidence emain/delegation-policy.ts:59, :70, :98, :112.
4. **High confidence, runtime and lease use independent deadlines.** Electron fixes lease lifetime at 300 seconds while Python accepts 0–900 seconds and conditionally has no native budget. A 600-second worker can lose surface authority at 300 seconds while continuing model work. Return the authoritative accepted deadline at prepare and pass remaining budget to worker admission/model/tools, with a fallback Python timer when the native library is absent. Preserve a distinct short cancellation/drain budget. Regression: fake time and test requested 1s/300s/600s and missing native helper; assert aligned worker and lease cutoff, and no fresh mutating action dispatch after cutoff. Evidence emain/delegation-policy.ts:10, :104, :117; agents/hermes/plugins/kronterm-tools/harness.py:107; agents/hermes/plugins/kronterm-tools/delegation.py:173.
5. **High confidence, completed marker is weaker than usable evidence.** Any one completed item with schema_valid absent or anything except false blocks further delegation and injects a handoff that promises results[].summary. Missing, blank, malformed, or partially failed outcomes can therefore cause a premature terminal handoff. Require explicit per-task status, validated output/summary, and outcome evidence; track partial batch coverage and allow a bounded repair only for eligible unfinished work. Test completed without summary, invalid schema, success plus failed sibling, and artifact-backed success; verify terminal versus repairable routing. Existing test accepts completed without summary when no turn identity is supplied. Evidence agents/hermes/plugins/kronterm-tools/delegation.py:15, :212, :216 and tests/test_smart_delegation.py:89 (under agents/hermes).
6. **High confidence in scaling shape, unmeasured impact.** WorkflowStore performs synchronous whole-journal JSON serialization, file write and rename on Electron's main thread, clones the whole store for rollback, and clones a full snapshot per listener. With frequent persisted swarm progress this scales with total history per transition and can delay UI/IPC/tool response. Keep user-facing transitions durable with ordered append/transaction semantics, project keyed deltas, and batch ephemeral progress. Regression/benchmark: seed realistic history then send 1/4/16-worker event bursts, record main-thread event-loop delay, bytes written and renderer payload bytes; kill/reopen between durable transitions and verify uncertain recovery plus subscriber monotonicity. Evidence emain/workflow-store.ts:190, :202, :219, :227 and emain/workflow-runtime.ts:25.
