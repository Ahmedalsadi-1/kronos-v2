# KronTerm OS — System UI Implementation Pack

KronTerm OS is a persistent AI work environment built over canonical live sessions. The implementation uses Apple system-UI principles for hierarchy, COSMIC/KDE/GNOME patterns for desktop completeness, and a distinct KronTerm visual identity.

## Current implementation sequence

1. Architecture, typed actions, and live identity
2. Durable project spaces and layout v4 migration
3. Connected shell and one app lifecycle registry
4. Shared System UI primitives and appearance authority
5. Integrated live window chrome
6. Files, Canvas, Activity, Control, Kronos, and recovery surfaces
7. Responsive shell and application overflow
8. Flat overview and keyboard switching
9. Native-surface qualification
10. Agent-control and regression validation
