# AppStream and agent input audit

Scope: AppStream input feedback, the shared agent cursor, and app mentions. Reviewed after implementation as requested. Existing unrelated workspace changes were preserved.

## Evidence

- Cursor renderer exercised in a real browser using its source module. Click and reduced-motion screenshots are in `output/appstream-input-review/`.
- Screenshot review: the short click pulse is local to the pointer, content remains readable, and reduced motion suppresses the pulse. The label stays within the surface edges (regression test).
- AppStream uses an explicit input error status and visible keyboard focus. Live capture remains distinguishable from compatibility fallback through its retry control.
- Focused tests cover Retina coordinate conversion, native scroll, action ordering, stale owner rejection, native failures, cursor disposal, curved browser drags, and app mention identity.
- A live Calculator observation and fractional native scroll completed without a native tool error. This does not establish successful scrolling in every app.
- Final TypeScript checking passed with an 8 GB heap. The final focused suite passed 100 tests across 13 files; subsequent prompt and native-session checks also passed. Targeted ESLint reported no errors and one existing empty-catch warning in stream shutdown.
- A small native-helper-only sample measured Calculator observations at 234.6, 201.3, and 245.8 ms. No end-to-end human-speed claim is supported.

## Findings

1. HIGH, R-35 / C-2: Full Electron end-to-end interaction remains unverified. Browser rendering and mocked IPC tests do not prove the rebuilt application's video capture, native input, app-window selection, or latency. Test the rebuilt application against both a Retina app and an app with multiple windows before making a production-readiness claim.
2. MEDIUM, C-2: The ordinary app stream still controls a host application. It does not provide a fully hidden embedded native application. Existing background virtual-display sessions only expose constrained accessibility actions; unrestricted hidden app interaction needs a separate VM or compositor/input implementation.

No additional decorative effects were introduced. The rainbow pulse serves click feedback, uses low opacity, and respects reduced motion. This is a scoped audit, not a product-wide design certification. No changes were made after this audit based on its findings.
