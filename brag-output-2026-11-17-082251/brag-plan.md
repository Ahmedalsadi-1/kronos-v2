# KronOS: From one prompt to a whole workspace

## Planning rubric
1. App: KronOS brings agent chat, preview, canvas, terminals, VMs, files and connections into a persistent desktop workspace.
2. Impressive claim: the chat is an entry point into a connected workspace, not the boundary of the work.
3. Visual hook: huge kinetic typography fractures into scattered app tiles, then resolves into one floating composer.
4. Actual UI: recreate the inspected dark rounded composer, plus source-grounded canvas tools and tabbed preview. Stylized demonstration, with fictional task data.
5. Shortest satisfying version: 25 seconds to make the typing and canvas reveal readable.
6. Tone: cinematic / kinetic, precise editorial type and continuous camera movement.
7. Audio: steady music, restrained click and soft impact accents, no narration.
8. Caption: Too many apps, not enough connection? Meet KronOS: chat, previews, VMs, tools, memory and bots in one connected workspace.
9. Flow: type a prompt -> view a working preview in chat -> open the canvas and reveal connected tools.

## Storyboard
- 0-3.8 (3.8s): exact hook, 'too many apps, not enough connection?' in two enormous lines. App-shaped tiles drift apart behind the type. Word groups snap in, sentence holds. Soft accents.
- 3.8-8.2 (4.4s): standalone rounded chatbox; cursor arrives, clicks, types 'Build my launch workspace.' and presses send. All unrelated UI remains absent. Light typing clicks.
- 8.2-11.5 (3.3s): preview grows directly above the same composer. Preview / Files / Terminal tabs, a fictional launch page. 'See it in chat.' holds. Cursor targets Open canvas.
- 11.5-15 (3.5s): continuous zoom-out reveals the same preview and composer in a canvas; tools arrive spatially and connectors trace between actual panels. 'Then open the whole canvas.' Soft reveal impacts.
- 15-21.3 (6.3s): fully settled connected canvas. VMs, browser/files/terminal, memory, bots and connections are legible; focus accents sequence across VMs, memory and bots. No claims of automatic job execution. 'VMs. Tools. Memory. Bots.' holds.
- 21.3-25 (3.7s): warm full-frame wipe; KronOS wordmark and 'Everything, connected.' settle. Private beta. Music fades.
Total: 25.0 seconds.
