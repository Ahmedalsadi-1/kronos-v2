## Edit and render

The complete HyperFrames project is `composition/`. Its media, fonts, audio and browser runtimes are local and linked. The ZIP does not require access to this machine's original source paths to play or render the current cut.

```sh
cd composition
node build.mjs
npx hyperframes@0.9.22 preview --background
npx hyperframes@0.9.22 check
npx hyperframes@0.9.22 render --quality delivery --fps 30 --workers 1 --output ../brag.master.mp4
```

- `build.mjs`: scene layout, shot durations and software camera transforms.
- `office.js`: actual Three.js room/hardware, camera, light response, display homography and companion poses. `build.mjs` derives `assets/office-runtime.js` from it.
- `compositions/`: editable scene HTML generated by `build.mjs`. Edit the builder for durable layout changes; direct scene edits work until the next build.
- `assets/media/`: trimmed, cropped, retimed genuine recordings.
- `assets/audio/mix.wav`: complete 80-second stereo mix. Original music and selected effects are included for remixing.
- `assets/audio/analysis.json`: per-frame sound energy; room fill response is bounded below 3%.
- `assets/vendor/three.min.js`: pinned Three.js runtime, version 0.187.0. `three-entry.js` is its bundle entry. Run npm install and esbuild only if changing that vendor bundle.

`prepare-media.py` rebuilds derived media from the original repository/Drive material. It skips existing derived files; remove the individual derived clip before rerunning if changing that clip's crop or trim. This step is optional for editing the delivered project, which includes all selected media.

The social export has the selected poster in frame zero; all subsequent picture frames retain their timing. `brag.master.mp4`, when present locally, starts directly in the dark office. `share-copy.txt` includes the music attribution required when posting.
